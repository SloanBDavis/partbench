# V25 Release Plan: Parametric single-part toolkit

Status: **In progress.**

Do not reopen V22, V23, or V24. Product SHA `a27c4a5`.

## Product goal

After V25, an agent or a person can model a general mechanical solid with the
parametric toolkit and not hit a "that family is deferred" wall, except the
non-goals below. Proof is a frozen command matrix plus CADOps scenarios per
row, not a sculpture. Do not shrink a Must row because a demo part did not
need it.

Must, one release:

1. Sketch splines. Usable as extrude/revolve/sweep profiles in the completed
   region path.
2. Associative offset: offset a sketch profile or a face as a real feature that
   edits/rebuilds, not a one-shot sketch mutation that drops intent.
3. Pattern any completed solid feature, not only `feature.hole` and not only
   whole bodies. Grow existing `feature.linearPattern` / `feature.circularPattern`.
   Seed is exclusive body XOR feature. Do not add a second pattern op.
4. `feature.combine` gains `intersect`. Union/subtract stay.
5. Body move/align onto a planar face, datum plane, or datum axis. `scene.updateTransform`
   is display-only and does not count.
6. Draft on a planar/planar-adjacent face set of a completed exact solid.
7. Sweep: composite path (existing line/arc plus spline where splines land).
   Drop the single-line leftover as a blocker. Keep failure structured when
   geometry is illegal.
8. Loft: non-parallel sections on the completed profile matrix. Drop the
   parallel face-attached leftover as a blocker.
9. Datum axes, and use them as circular-pattern axes / align refs. Planes
   already exist from V24. Do not add a datum-CSYS family unless an existing
   collector cannot take an axis or plane.

## Why this

V24 made three proof parts finishable and called that "parts done." The toolkit
still refuses splines, associative offset, feature-pattern beyond hole, intersect,
align, draft, composite sweep, non-parallel loft, and datum axes. That is the
bottleneck. One release. Push/pull is out.

## Binding rules

1. CADOps is the center. Human UI and the connected agent submit the same
   batch. Do not add an MCP tool unless `cad.batch` cannot express the ops.
2. Reuse V13 checkpoint/anchor plus V23 promotion.
3. New source records are allowed. Prove a project-schema bump is required
   before adding one. `.wcad` stays `partbench.wcad.v2` unless a persist gap is
   recorded in this plan first.
4. Universal selection is not universal commandability.
5. Approval modes stay `manualApproval` and `approveAll`.
6. Vertices stay inspect-only.
7. Do not add a workspace package or production dependency unless this doc
   names it.

## Frozen matrix

Facts in the current protocol. Do not invent a second copy of these ops.

- No sketch spline entity. `bspline` exists only as a topology class on kernel
  curves/surfaces. There is no `sketch.addSpline`.
- `sketch.offset` is a one-shot curve edit. It is not an associative feature.
- `feature.linearPattern` / `feature.circularPattern` seed is exclusive
  `seedBodyId` XOR `seedFeatureId`. Cad-core accepts `seedFeatureId` only for
  a completed `feature.hole`.
- `feature.combine` mode is `union` | `subtract`. No `intersect`.
- `scene.updateTransform` moves display primitives. It is not body align.
- No `feature.draft`. No `feature.align`. No `datum.axis.create`.
- `datum.plane.create` and grown `sketch.create` (`plane` XOR `datumId`) stay.
- `feature.sweep` already takes a path ref / entity id list. The leftover is a
  single-line blocker in the engine, not a missing op name.
- `feature.loft` already takes a sections list. The leftover is a parallel
  face-attached blocker in the engine, not a missing op name.

### Existing collectors that grow

| Collector / op | Today | V25 |
| --- | --- | --- |
| Sketch profile | line, arc, circle, rectangle, slot, rounded-rect, regions | Also spline. Extrude/revolve/sweep consume it on the completed region path. |
| `sketch.offset` | one-shot curve edit | Keep as mutation. Associative offset is a new feature, not this op. |
| Pattern seed | body XOR `feature.hole` | XOR any completed authored solid feature listed below. No second pattern op. |
| Circular-pattern axis | global axis, generated/named/anchor edge | Also a datum axis |
| `feature.combine` | `union` \| `subtract` | Also `intersect` |
| `feature.sweep` path | single-line leftover blocks composite | Composite line/arc/spline. Structured fail when geometry is illegal. |
| `feature.loft` sections | parallel face-attached leftover | Non-parallel sections on the completed profile matrix. Structured fail when geometry is illegal. |
| Mirror / sketch plane | world, face, V24 datum plane | Keep. Datum CSYS is not added. |

Frozen patterned seed kinds: `extrude`, `revolve`, `hole`, `chamfer`, `fillet`,
`combine`, `shell`, `sweep`, `loft`, `mirror`. Body seed stays. Nested
pattern-of-pattern is deleted (identity mess, not a Must row).

### New CADOps

| Op | Why it is missing | Consumed by |
| --- | --- | --- |
| `sketch.addSpline` | No sketch spline entity | Region-path extrude/revolve/sweep |
| `feature.offset` | `sketch.offset` drops intent on rebuild | Sketch profile or face, edit/rebuild |
| `feature.align` | No document-true body move | Planar face, datum plane, datum axis |
| `feature.draft` | No draft family | Planar/planar-adjacent face set |
| `datum.axis.create` | Only datum planes exist | Circular-pattern axis, align ref |

`feature.offset` source is a sketch profile or a face (generated, named, or
active-anchor, including V23 promotion). Distance and side rebuild. Do not
replace `sketch.offset`; that mutation stays for trim-like edits.

`feature.align` moves a completed exact body so a planar face on it meets a
planar face, a datum plane, or a datum axis. Do not reuse `scene.updateTransform`.

`datum.axis.create` is document source, same as V24 planes. Grow the existing
circular-pattern axis collector. Do not add a datum-CSYS family.

Spline is interpolation or control-point sketch geometry, not Class-A surfacing.

## Delete, do not park

- push/pull, direct B-rep edit
- assemblies, mates, drawings, PMI
- production WebGPU or a second renderer
- NL parser, hosted MCP, third approval mode, agent file authority
- sheet metal, Class-A surfacing
- cosmetic/modeled threads
- ribs as a new family (use extrude)
- gzip ceilings and production-browser gauntlets as closers
- vertex commandability
- a Playwright suite
- a second product release
- shrinking a Must row because a demo part did not need it
- nested pattern-of-pattern
- datum-CSYS unless a collector cannot take an axis or plane

## Keep from V24

`feature.combine` union/subtract. `datum.plane.create`. Grown `sketch.create`.
Hole-pattern. Current-exact promotion. Same CADOps for human and agent.
Canvas 2D. `web-cad.project.v22` and `partbench.wcad.v2` until a slice proves
a persist gap. The V24 named closer stays as passed history. Do not replay it
to close a V25 slice.

### Named closer

```sh
pnpm smoke:v25-part-toolkit
```

That command runs `scenarios/` per Must row and checks UI Apply parity.
Add the script when those scenarios exist. `pnpm verify` stays typecheck plus
`scenarios/`. Do not rerun V7–V24 gauntlets.

## Definition of done

V25 is complete only when:

1. Every Must row has a green `scenarios/` case and UI Apply parity.
2. Human UI and MCP/agent submit the same CADOps.
3. Vertices remain inspect-only.
4. Push/pull, assemblies, mates, drawings, PMI, WebGPU, NL, hosted MCP, sheet
   metal, Class-A, threads, ribs-as-family, Playwright, and vertex
   commandability stay out.
5. V22, V23, and V24 stay closed.

End of V25 release plan.
