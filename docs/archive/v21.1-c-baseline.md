# V21.1 Gate C Closure

- Recorded: **2026-08-02**
- Implementation commit: `f144508`

## Landed Product Path

- Circular blind and through-all holes in both directions now consume the one
  verified exact-body artifact for every source family and for one-or-more
  solids. Whole-shape cuts preserve non-intersected solids and reject
  no-intersection, tangency, full removal, invalid, stale, cancelled, and
  corrupt results atomically.
- `feature.updateHole` retargets in one source transaction, retains feature and
  result-body IDs, swaps target lifecycle, invalidates topology evidence, and
  preserves undo, redo, replay, and save/open behavior.
- Human create/edit and connected-browser agent commits project the same CADOps
  batch, build every affected exact hole result, and commit only at the captured
  source-authority epoch. Standalone adapters retain source dry-run but reject
  hole commits because they have no browser exact runtime.
- Solid editors and contextual actions use current source resolution plus exact
  metadata, list all body families, retain disabled root diagnostics, warn for
  multi-solid targets, and source-dry-run each prospective retarget for
  self/descendant/cycle legality.
- The superseded mesh-hole preflight and imported-hole recipe blocker were
  removed. STEP export and hole preflight now share the existing exact-artifact
  DAG builder; preflight work has its own cancellation kind and cleanup path.
