# Connected robot arm

This example revises the [original agent trial](../robot-arm-trial/README.md)
into a connected assembly. It reuses the intended XY/XZ part geometry:
11 exact part definitions, 29 instances, one fixed root, and 28 `revolute`
mates. Those mates include controlled arm joints, hardware mounts with constant
angles, and gripper jaws driven by axial offset parameters.

Headless exact/native/STEP verification and both browser journeys pass. See the
[current goal and proof record](../../docs/robot-arm-fixes.md) for the completed
integration checks and the landed commit.

## Source and revision

[model.mjs](./model.mjs) exports the original sketch, solid, and explicit-region
operations, `assemblyOps()`, `revisionOps`, and independent expected pivot math.
It produces ordinary CADOps for the existing `cad.batch` tool. It does not
implement another modeling API or compute replacement instance poses for the
revision.

The revision changes upper-arm pivot spacing from 160 to 180 mm, jaw clearance
from 20 to 35 mm, and shoulder angle from 60° to 75° in one batch:

```json
{
  "allowCommit": true,
  "batch": {
    "version": "cadops.v1",
    "mode": "commit",
    "ops": [
      { "op": "parameter.update", "id": "upper_span", "value": 180 },
      { "op": "parameter.update", "id": "gripper_opening", "value": 35 },
      { "op": "parameter.update", "id": "shoulder_angle", "value": 75 }
    ]
  }
}
```

The old trial needed 89 operations to change length and opening: two parameter
updates followed by 29 instance deletions, 29 insertions, and 29 mate creations.
This example uses three parameter updates, also changes the shoulder angle,
and retains the instance and mate IDs. This is a reduction in authored
operations, not a measured speed comparison.

Pivot frames reference authored sketch circle centers. Dimension evaluation
moves those centers when the link length changes; the assembly solver then
keeps the connected pivots attached. Hardware follows the same connections.
Jaw offsets bind to `jaw_upper = gripper_opening / 2 + 7` and
`jaw_lower = -gripper_opening / 2 - 7`, accounting for the 14 mm finger thickness.
The closer checks actual jaw clearance, not just the parameter value.

## Run and inspect

Use Node.js 22 and pnpm 10 from the repository root:

```sh
pnpm install
pnpm smoke:robot-arm
```

The closer builds the headless stdio executable and drives real MCP sessions.
It checks profile discovery/validation, both original solid authoring paths,
exact volumes and centroids, connected pivots, dry-run preservation, three-op
revision, invalid-reference rollback, root motion, fresh-process native reopen,
and another revision after reopening. It exports STEP and independently reads
it back through OCCT, checking 11 solids and total volume.

Outputs are gitignored and regenerated by the command:

- `.metrics/robot-arm-workflow/verification.json`: latest successful headless report.
- `.metrics/robot-arm-workflow/robot-arm-initial.wcad`: original connected pose.
- `.metrics/robot-arm-workflow/robot-arm.wcad`: revised connected arm.
- `.metrics/robot-arm-workflow/robot-arm-definitions.step`: eleven part definitions.
- A timestamped directory preserves each successful run's files.

Inspect `cad.project_structure` for instance IDs, resolved transforms and mates;
use `cad.body_mass_properties` for exact definition geometry. The
[public usage guide](../../docs/agent-runtime-usage.md#connected-assemblies)
documents operation fields, frames, radians versus degrees, and parameter
bindings.

The workbench's **Model view** control selects **Assembly** for posed instances
or **Parts** for the definitions. Selecting an assembly returns to Assembly view;
definition inspection uses Parts view. After generating the native artifacts,
run the browser closer (requires Bun 1.4.2+ and Chrome):

```sh
pnpm smoke:robot-arm:browser
```

It opens the headless-generated native arm, edits a joint angle, uses Undo/Redo,
changes link length, checks the connected pose and exact volume, and rejects an
empty angle. A second small journey creates a sketch-pivot joint and moves its
root through ordinary controls. Both use a fresh tab for the invalid-input case.
The existing fast assembly regression command remains `pnpm smoke:e2e`.

## Supported boundary

Connections form a rooted forest. Compatible parallel constraints between the
same pair are supported; this is not a general closed-loop mechanism solver.
The example controls joint angles and jaw offsets numerically. It does not
simulate motion dynamics, detect collisions, or establish manufacturability.
Revolute-connected instances require unit scale; edit their source dimensions.

Native `.wcad` retains the assembly source, mates, bindings and poses. STEP
exports selected part definitions; it does not export 29 assembled occurrences
or an assembly/mate hierarchy. No native format version or MCP tool was added.
